# Smart Energy Optimization - Full Application

## Run
python -m pip install -r requirements.txt
python -m streamlit run app.py

## Included
- Food, Textile and Automotive virtual factories
- Live energy dashboard
- Machine control simulation
- Exact peak ON/OFF reset
- Demand forecasting
- Peak risk detection
- Abnormal consumption alerts
- Dynamic production-safe optimization
- Flexible-load selection
- What-if simulator
- Machine offline/failure simulation
- Explainable optimization
- Energy cost and CO2 indicators
- Optimization history and CSV export

All values are simulated prototype data.
